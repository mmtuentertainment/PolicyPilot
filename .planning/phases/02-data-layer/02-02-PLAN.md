<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Clerk Dashboard → operator clipboard → `.env.local` | The webhook signing secret crosses from Clerk's UI through the clipboard into a local gitignored file. Leakage at any step (e.g., screen-share, clipboard manager, OS paste history) compromises the ability to spoof Clerk webhooks. |
| Supabase Dashboard → operator clipboard → `.env.local` | Three DB connection strings cross. Each contains an embedded password (Supabase pooler URI format: `postgresql://postgres.<ref>:<password>@host`). Leakage compromises DB access. |
| `.env.local` → git | MUST NOT cross. `.gitignore` is the only gate. Existing line from Plan 01-02 is the existing protection. |
| Operator's dev tunnel → Clerk's webhook delivery network | Clerk POSTs signed payloads through the tunnel to localhost. Tunnel itself is HTTPS (ngrok / Cloudflare); the svix-signature header is the real integrity gate. A man-in-the-middle that doesn't have the signing secret cannot forge requests. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
