## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public web → marketing pages | Untrusted users hit `/`, `/pricing`, `/sign-in`, `/sign-up`. No auth required, no PII collected, no DB access. |
| Public web → Clerk hosted UI | Sign-in / sign-up form is rendered by Clerk's client SDK; credentials post directly to Clerk's API, never to the PolicyPilot server. |
| Authenticated user → `/sign-in-success` | Placeholder page; reachable only with a valid Clerk session (Plan 04 middleware enforces). No data displayed. |
