## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-15 | Denial of Service | duplicate event emails on repeat assign/publish | mitigate | `policy_assigned` gated on `PolicyAssignments.create` RETURNING length>0 (onConflictDoNothing); `policy_updated` gated by the `policy_versions` version-unique constraint — duplicates emit nothing (D-04). |
| T-7-16 | Tampering | email failure rolling back assign/publish | mitigate | Emission is post-commit + try/catch; an email error is logged (masked) and never fails the action or the DB write. |
| T-7-11 | Spoofing | worker → endpoint call without secret | mitigate | Worker sends `Authorization: Bearer ${CRON_SECRET}` read from Railway env; the route's R7-1 gate rejects anything else; secret never logged or committed. |
| T-7-17 | Denial of Service | worker stays alive → Railway skips next run | mitigate | `process.exit()` in every code path (missing-env, success, non-ok, catch). |
| T-7-05 | Information Disclosure | CRON_SECRET in worker logs | mitigate | Worker logs status + body only, never the Authorization header or secret value. |
| T-7-SC | Tampering | npm installs | mitigate | Worker is dependency-free (built-in `fetch`); this plan adds ZERO packages. |
