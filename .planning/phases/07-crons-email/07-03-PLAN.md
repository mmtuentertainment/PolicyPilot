## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application → Resend API | Server-only email send; the API key crosses no client boundary (`server-only` guard). |
| user-controlled policy title → rendered email | Policy titles are admin-authored, untrusted text that flows into email HTML. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-7-06 | Tampering | policy title rendered into email HTML | mitigate | Titles render as JSX text nodes (React Email auto-escapes); no `dangerouslySetInnerHTML`, no string interpolation into raw HTML. |
| T-7-05 | Information Disclosure | RESEND_API_KEY | mitigate | `getResendClient()` lazy singleton reads env via `server-only` module; key never logged; `ResendSendError` carries a masked recipient, never the key or full address. |
| T-7-07 | Information Disclosure | recipient email in error logs | mitigate | `maskEmail()` applied before constructing `ResendSendError`; structured masked logging only. |
| T-7-SC | Tampering | react-email / resend import surface | mitigate | Packages installed under Plan 07-02's blocking-human checkpoint; templates import only the consolidated `'react-email'` surface. |
</threat_model>
